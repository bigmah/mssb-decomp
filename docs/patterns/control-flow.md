# Matching patterns: control-flow

if/else vs switch, early returns, bool/int returns, compare and branch shapes. One pattern per line, so `grep -i <keyword> docs/patterns/*.md` returns whole entries.

- **menus `lbl_80371C30` object-table writes (auto_00_00071EC4_text, 12 functions):** write `((u8**)lbl_80371C30)[(K + *(u16*)(o + 0x14) + i) * 2]` with the constant FIRST; `*(u16*)(o+0x14) + i + K` gets reassociated and the `+K` is CSE'd, which the original never does. Entries read as `*(u8**)(lbl_80371C30 + o14 * 8 + OFF)` for `lwz OFF(rN)` after `add`, and `((u8**)(lbl_80371C30 + OFF))[o14 * 2]` for `lwzx`. State-machine heads: `u8* e = lbl_803C66B0 + i; if ((*(e += 0xD) == 0) ? 1 : 0)` gives `lbzu` + `cntlzw/srwi.`; later tests use `*e`.
- **`bne L; b end` before a body (instead of a plain `beq end`):** the original guard was one `||` chain, `if (i < 0 || i >= 100 || tbl[i] == 0) return;`, not nested ifs or separate early returns (m_sound fn_3_8BA60).
- **Struct-array element address:** if the original does `mulli; add; lwz 0x80(r3)` but we get `mulli; addi 0x80; lwzx`, index a typedef'd struct of the right size instead of `u8*` plus a byte offset. For a plain `u8*` base, `u8* f = base + i * SIZE; f[OFF]` (separate pointer) often fixes the same thing.
- **`fndiff` line counts do not track the objdiff score;** trust `build/GYQE01/report.json`. A `DATA` vs `lbl_...` name difference in `fndiff` is noise if the report says 100%.
- **`switch` on an `s8`** reproduced an odd `beq`/`b` shape; `*(s16*)(p+off) += 1` matched where `x = *p; if (x < N) *p = x + 1` did not.
- **`fndiff` MATCH can hide branch-target differences.** It ignores label names, so a branch that jumps to the wrong place still prints MATCH (`fn_3_A0F0` had `done == 0` outside the `if`). Always confirm 100.0 in `build/GYQE01/report.json` (fuzzy_match_percent) before committing.
- **`x == 5 || x == 6` became `subi/clrlwi/cmplwi 1/ble`:** CW folds a range check on a cached local. Re-read the global in each compare (`*(s16*)(g+0xC4) == 5 || *(s16*)(g+0xC4) == 6 || ...`) to get the original `cmpwi 5; beq; cmpwi 6; beq` with one `lha` (`fn_3_85744`).
- **Nested early returns `bge L; b L` SOLVED:** write the guard as one early-return `if (a != 7 || b != 6 || x > 4 || x < 0) { return; } call();` (fn_3_150010, fn_3_14DC80, fn_3_15521C, fn_3_14CB28, fn_3_14A070 `if (n > 4 || n == 0 || src == NULL) return;`). Positive `&&` guards wrapping the body give `beq L` instead; use the positive form only when the original has plain `bne L` (fn_3_14C904).
- **Redundant `beq L; beq L` pair:** write the condition as `a == 0 || (a != 0 && ...)` (`fn_3_111AC4`).
- **`bge L; b L` nested early returns (fn_3_BD6AC):** `if (v < 0xD) { if (v >= 0xB) call(); }` and the `return`-style forms all give `blt`; `switch (v) { case 0xB: case 0xC: call(v == 0xC); break; }` produces the original `bge L; b L` shape.
- **`blt end; cmpwi 2; ble body; b end` range guard:** `if (i < 0 || i > 2) return;` (fn_3_118358); `switch` and nested `if`s gave other shapes.
- **`cmplw rCnt, rI; ble` vs `cmplw rI, rCnt; bge`:** write the compare with the loaded field on the left (`if (*(u32*)(d + 0x3C) > i)`) (fn_3_FD408).
- **`beq L; blr` before the body (instead of `bnelr`) for an `A || (B && !C)` guard:** write it as an early return, `if (!(A || (B && C == 0))) { return; } body;` (fn_3_3ABF0). `if (A || ...) { body }` and nested-`if` forms gave `bnelr`.
- **`else return;` vs `!= x return`:** `if (c == 3) { stores } else { return; }` reproduces `bne; ...; b L; blr` dead-blr shapes (fn_3_7EBD4); the early-return form drops the dead `blr`.
- **Unsigned byte compared with `cmpwi` (no `extsb`):** load into an `s32` local (`s32 a = t[0x441C];`); `u8` local gives `cmplwi`, `s8` adds `extsb`. A typed struct with an `arr[1]` member kept the `addis` base in r3 (menus fn_2_30D80).
- **`x==1 || x==2` merged to `subi/cmplwi`:** re-read the global in each compare, no local (fn_3_5C418).
- **Direct global read vs base pointer (sta_c2 fn_3_CF72C):** `stad = g_d_GameSettings[9]; if (g_d_GameSettings[7] == 6)` (re-reading the global each time, `extern u8 g_d_GameSettings[]`) matched where `u8* gs = g_d_GameSettings; gs[9]/gs[7]` hoisted the table lookup above the branch. Also `lbl[mode==6]`-style data tables that the original reads as `lis; lbz sym@l` are separate scalar symbols; a two-field struct extern still gave `addi`.
- **Forcing a reload after a store (fn_1_F50C):** `*(s16*)(q + 0x3C) = *(u16*)(q + 0x3C) - 1; if (*(u16*)(q + 0x3C) == 0)` gives `sth; lhz; cmplwi`; `--*(u16*)p == 0` or a same-typed pair folds the reload away.
- **Read branch targets in the raw `.s`, not the `fnstart` listing (menus 1254, fn_2_87A8):** `fnstart`/`fndiff` print every label as `L:`, so `bne L` can look like it jumps to the next block when it really goes to the epilogue. Check `build/GYQE01/<module>/asm/<unit>.s` (`.L_XXXX` names). fn_2_87A8's `cmplwi; bne end; lbz; cmplwi; beq body; b end` is the plan's `||` early return, `if (a[0x55] != 0 || a[0x56] != 0) return;`.
- **Several `||` compares of one `x & mask` merge into subi/cmplwi ranges**; the original's unmerged `cmplwi r0,N / beq` chain came from `t = f(); t &= 0x7F; if (t==2||t==3||...) return 1; else return 0;` with an explicit `else` (`fn_3_B7C2C`).
- **`int` vs `bool` returns:** callers compare with `cmpwi` only if the callee prototype returns `int`; for `checkTriangleCollisions` the local `ret` had to be `int` (not `bool`) for the callee to keep matching.
- **`__abs(x)`** gives the branch-free `srawi/xor/subf` abs (plain `abs` becomes a `bl`).
- **`if (x == 1) ... else if (x == 2)` vs `switch`:** an if-chain on a u8 gives `cmplwi/bne`, a `switch` gives `cmpwi/beq/bge`. A single-case `switch (u8) { case 1: return 20; } return 20;` gives the `cmpwi 1; beq; b` shape (fn_3_110A38). Use `*(s8*)&field == 1` / `= -1` when the original compares or stores a signed byte without extsb (fn_3_20CEC).
- **`bne L; b end` after a range check, SOLVED (fn_3_8B890, fn_3_8BA60):** one combined early return, `if (i < 0 || i >= 100 || flags[i] == 0) { return; }` (the pattern above for nested early returns). Nested ifs, `goto` and helper forms all gave a single `beq`.
- **Binary-search `switch` with an extra leaf/dead `b`:** if the compare tree has pivots for ranges that only jump to the end, add empty `case X: case Y: break;` labels for those values. Brute-force the set of empty cases with a script (`fn_3_BD504`: `case 11: case 12: break;` produced the dead `b L` after `b 15F574`).
- **`cntlzw; srwi; cntlzw; srwi` after a call is `return !!f(...);`** (fn_3_134C80). `f() != 0` gives `neg/or/srwi`.
- **`p == 1 || p == 2 || p == 3` on a `u8` folds to a `subi/clrlwi/ble` range test (fn_3_8A7B4);** the original's three separate `cmplwi/beq` come from `if (!(p != 1 && p != 2 && p != 3))` (or reading the array element directly in each term).
- **Update-form load `lhau r0,0xEE(rN)` (fn_3_88228):** `u8* q = g_Runners + off; if (*(s16*)(q += 0xEE) == 1) { ...; *(s16*)q = 2; }` (the `+=` inside the condition) makes CW fuse the add into `lhau` and store via `0(rN)`. A separate `q += 0xEE;` statement does not.
- **Switch with two adjacent empty cases to the same target (fn_2_3735C):** CW merges them into a bare `cmpwi N; bge default` pivot; `case 0x24: case 0x25:` vs `case 0x24:` alone changes `beq` emission. Brute-force the set of empty cases with `fnvariants`.
- **`neg; or; srwi 31` return:** `return !!result;` (fn_2_194xx family); `result != 0` schedules the `srwi` too early.
- **Known blocker:** `(v = p[0x34]) == d1 || v == d2` emits `cmpw d1,v` on the first compare where the original has `cmpw v,d1` (fn_2_71B80, fn_2_71A70, fn_2_6CBB0 all differ by only that line).
- **fndiff says only labels differ but objdiff reports 99.99% (fn_2_3C7DC):** fndiff normalises branch targets, so a branch to a different block is invisible. Disassemble our object (`build/tools/dtk elf disasm build/GYQE01/src/<unit>.o out.s`) and diff the function against the target asm with labels kept. Here `if (i == 5) { if (x == 0) ... } else if (i == 19)` had to be `if (i == 5 && x == 0) ... else if (i == 19)` (the failed inner test falls through to the next `else if`).
- **Unsigned byte compared with `cmpwi` instead of `cmplwi` (fn_2_42BE8, fn_2_3FDE0, fn_2_3CD34):** cast the load to `(s32)`: `(s32)e[0x31] == 1`. A `switch` on an u8 field with an extra `b` to the end in the compare tree wanted an empty `case 3: break;`.
- **`bne L; b end; L:` for a NULL check (fn_80014990):** `if (x != NULL) goto found;` inside the guarded block, `return;` after it and the body under a `found:` label. The same shape with `return 0` at the very end of a `do { if (!f()) goto fail; ... } while (...); return 1; fail: return 0;` loop (fn_80016F7C).
- **`cmplwi 1; beq end; cmplwi 2; beq end; cmplwi 3; bne body; b end` (fn_2_9257C):** `if (g->f == 1 || g->f == 2 || g->f == 3) return;` reading the field each time; caching it in a `u8` local turns the chain into a range check (`subi; clrlwi; cmplwi; ble`), and a `switch` gives a `cmpwi` tree.
- **fndiff says MATCH but report.json < 100% (fn_3_ADEDC 99.96):** fndiff normalises branch labels, so two identical `case` bodies emitted in swapped order are invisible; compare label targets (case order in the switch is what differs; write the cases in the order the asm lays the bodies out).
